
# Taller UX/UI

Formulario de inscripción a talleres, rediseñado aplicando principios de UX/UI.

## Mejoras realizadas

- Se agregaron etiquetas a los campos.
- Se mejoraron los colores y tamaños de letra.
- Se implementaron validaciones.
- Se agregaron mensajes de confirmación.
- Se mejoró la navegación con el teclado.
- Se agregó confirmación antes de limpiar el formulario.

## Evaluación de accesibilidad

- Lighthouse Accessibility: 100/100.
- Navegación con Tab: correcta.

## Principios aplicados

| Principio | Aplicación |
|---|---|
| Ley de Fitts | Botones más grandes y fáciles de seleccionar. |
| Ley de Hick | Opciones de talleres organizadas por grupos. |
| Ley de Miller | Formulario dividido en secciones. |
